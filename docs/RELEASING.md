# 使用说明

> 程序目前仅测试了 1.18～1.21.1 的游戏版本，如有问题欢迎反馈。

发布包内的 `使用说明.html` 已内嵌全部截图，双击即可在浏览器中离线查看。

## 1. 接口配置

### 1.1 本地小模型

> 开始前请确认选择了正确版本的程序包：通用-CPU、AMD-VULKAN、NVIDIA-CUDA。

点击“添加接口”，选择“本地 GGUF”，然后填写接口名称。
在下一步选择已有 GGUF 文件，或选择 HY-MT-2 / Index-Translate 预设与下载保存位置，再选择配套模板。
点击“添加接口”保存已有模型；选择下载预设时，点击“添加并下载”，下载完成后会自动激活该接口。

![激活本地模型](./assets/activate-gguf.png)

本地模型可选 HY-MT-2 `7B` / `1.8B`、Index-Translate `9B` / `2B`，均为 `Q4_K_M` 量化。
请根据内存和显存容量选择；较小模型更适合 CPU。本地 GGUF 顺序翻译，本地 API 默认并发为 1。
每个本地模型独立显示为接口卡片，分别保存文件、模板和推理参数。
激活其它本地接口不会覆盖原来的 HY-MT-2 / Index-Translate 接口；删除接口配置仍保留模型文件。
已有版本的本地模型与历史模板绑定会迁移到接口列表，接口名称按模型身份识别，不随模板改变。

![本地模型接口菜单](./assets/test-gguf.png)

### 1.2 大模型 API

> 非强依赖，本地小模型足以处理大多数内容；但如果您需要 kubejs 翻译、翻译校润等功能，则必须配置此接口。

1. 点击右上角“添加接口”，选择对应供应商进行添加。

   ![添加接口](./assets/interface-add.png)

2. 添加成功后点击“测试接口”，确认可用性。

   ![接口操作菜单](./assets/interface-menu.png)

3. 可选：点击“激活接口”，切换当前接口为全量处理（推荐不激活，仅作为 kubejs 与校润兜底即可）。

添加接口时选择“专用翻译模型”或“大模型”，并从下拉框选择对应的翻译模板。
远端接口默认并发为 3，可在“调整参数”中修改；已有接口的显式并发值会保留。
KubeJS 脚本翻译与修润仅选择大模型接口。

### 1.3 Index-Translate 官方免费 API

接口列表内置 `Index-Translate · 官方免费 API`，激活即可使用，无需密钥或下载模型。
默认模型为 `Index-Translate-35B-A3B`，地址为 `https://index-translate.bilibili.com/v1`，默认并发为 3。
本地与远端共用 Index 模板格式，并关闭思考输出。服务可用性以官方为准。
连接方式见[官方调用示例](https://github.com/bilibili/Index-Translate/blob/main/inference/llm/call_api.py)。

### 1.4 提示词模板

在“提示词”页创建、复制、编辑或恢复模板；也可右键接口卡片选择“编辑翻译模板”。
系统与用户提示词均完整显示，`{text}` 表示待翻译文本，`{source_language}` / `{target_language}` 表示语言名。
`{glossary}`、`{context}` 分别表示命中术语与背景，`{preservation_rules}` 用于掩码重试时的动态保留规则。
`[[可选段落]]` 中的占位符为空时，整段省略。编辑器提供实际请求预览。

模板保存后，在添加或编辑接口时选择绑定；本地 GGUF 也在自己的接口弹窗中选择模板。
共享模板的修改会影响所有绑定接口的新请求，已有任务继续使用保存的模板快照；需要更新时勾选续跑的当前配置选项。
HY-MT-2 模板可定制，但模型仍仅支持中文输出；Index-Translate 与大模型支持其它目标语言。
Index 提供默认直译及术语与约束两份预设，格式参考[官方中文提示词示例](https://github.com/bilibili/Index-Translate/blob/main/docs/prompts_zh.md)。

### 1.5 翻译测试

在“翻译测试”中独立选择本地 GGUF、已配置的 API 或内置 Index 官方免费接口。
选择接口后自动带入它的配套模板，也可以临时换用其它模板，输入同一段原文和背景对比译文。
测试使用所选接口的参数及当前语言、术语和禁翻设置，不更改整合包的激活接口或模板绑定。
编辑模板后返回测试页即可使用最新内容；Index 的关闭思考设置、HY-MT-2 的中文输出限制继续保留。

点击“预览提示词”可查看按当前原文和背景拼接的系统、用户消息，包含预算内命中术语和禁翻保留标记。
预览不发起翻译请求；本地 GGUF 预览需要加载模型，以使用实际分词器计算术语预算。
可切换查看首轮直译和仅在校验失败时使用的掩码重试内容，也可复制提示词。
试译结束后，此区域会显示本次实际使用的提示词；原文或配置改变后，旧预览会清除，需重新生成。
